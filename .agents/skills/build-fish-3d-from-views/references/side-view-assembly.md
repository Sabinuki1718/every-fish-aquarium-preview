# 側面素材から胴体と鰭を組み立てる

側面の輪郭と模様を生かしやすい標準的な体型で優先する。側面を生成したら、採用するファイルと版をユーザーへ提示し、明確な承認を記録してから鰭なし素材・追加方向の生成と3D制作に進む。胴体を長軸に沿った断面の列で表せる、おおむね左右対称の魚が候補。Fish Kitを使った試作ではシロギス、ハマフエフキ、ルリヤッコで確認した。

ヒラメのように左右非対称の魚や、マゴチのように上下に平たく頭部の幅や断面が大きく変わる魚は、先に複数方向の資料を読み、体型に合う構造を選ぶ。この3種の試作から平たい魚への適用精度は判断できない。[体型別の組み立て方](modeling.md)と[図面の選び方](../../create-fish-3d-views/references/model-view-selection.md)を参照する。

## 素材と目印をそろえる

1. 承認済みの側面図から、吻端、尾鰭の先、尾柄の上下、眼と口、各鰭の外周と付け根を取る。上面・下面・正面がある場合は長軸をそろえ、胴体の幅、左右の付け根、鰭の開き角を確認する。側面だけで確定できない厚みや左右の模様は、資料と補完の根拠を `research.md` に分けて残す。
2. 側面素材は元画像と、鰭の重なりや影を除いた胴体用画像に分ける。元の側面図があれば使い、魚種名から作る場合は調査した識別形質を生成プロンプトに入れる。鰭のない胴体が必要なら、局所補間や利用可能な画像編集で作る。生成編集を使ったときは元画像と位置を合わせ、尾柄・口・眼の位置や体色を比較する。ずれや描き変わりがある箇所は元画像で確認する。
3. 胴体、背鰭、臀鰭、尾鰭、左右の胸鰭・腹鰭を、実際にあるパーツに分けてマスクを保存する。画像に隠れた反対側の対鰭も資料に沿って配置する。尾柄と隣の鰭の間では、背景が見える切れ込みと、胴体に連続する鰭の付け根を別々に記録する。魚ごとの断面・目印・マスク・補完の根拠は組立スクリプトと一緒に保存する。

鰭なし素材は三面図フローにも利用できる。鰭を消す編集で体形・模様が変わっていないか、元画像と吻端・眼・口・尾柄・胴体輪郭を重ねて確認する。鰭本体だけでなく影・外縁線・白い霧状の残りを除く。胴体輪郭マスクと鰭の接合帯を分け、背景除去で根元まで削らない。位置合わせと補修範囲を記録し、追加方向にも同じ清掃を適用する。

### 胸鰭に隠れた模様をつなぐ

- 全体の位置を合わせた後、胸鰭の周囲で体側の帯の両縁、鰓蓋線、隣接する斑点の中心と大きさを承認側面に重ねて比較する。吻や眼が合っていても帯の位置はずれ得る。ハチマキダテハゼのような斜めの帯は、体高の複数の位置で両縁を合わせてからUVへ焼く。
- 合成の継ぎ目はできるだけ模様を横切らない所に置く。ヤマブキハゼでは、帯の途中で画像を切り替えると二重の縁が出たため、帯全体とその周囲まで補修範囲を広げた。元の胸鰭の基部・鰭条・影と、半透明の胸鰭越しに見えていた体色が二重に残っていないか確認する。
- 実GLBでは、左右それぞれの胸鰭を検品用に隠した状態で、胴体の模様と鰓蓋線を拡大する。次に鰭を表示し、開閉の両端で基部の浮き、模様の欠けや二重描画、鰭膜越しの見え方を確認する。

## モデルへ組み立てる

1. 側面の高さと、上面・下面から読んだ幅で胴体断面を作る。輪郭を平滑化した後、尾柄の上下が背景へはみ出していないか元画像に重ねて確認する。口の合わせ目と眼の突出量は顔の拡大で確認する。
2. 鰭を独立した形状として置く。胸鰭の基部は側面図の付け根の線に合わせる。腹鰭は正面・下面で基部の間隔と開き角を確認する。背鰭・臀鰭の接合帯は少し胴体へ差し込み、足りない膜は同じ鰭の近傍から色を延ばす。尾柄の切れ込みに背景色を貼らない。尾鰭は尾柄と接続させ、隣接する薄い鰭が同一平面で重なってちらつかないようにする。[鰭の接合](fin-junctions.md)を参照する。
3. 清掃した胴体色と鰭の画像を別のUV領域に焼く。尾柄の灰色の塗り残しは、胴体輪郭のはみ出しと鰭マスクに入った背景を分けて直す。[魚種別の鰭仕様](model-contract.md#鰭の仕様)で薄い膜と判定した胸鰭は胴体の色を膜に焼き込まず、独立した半透明材質と基部からの鰭条で表現する。[鰭の半透明化](../../make-fish-fins-translucent/SKILL.md)を参照する。
4. 既存の [ローカル実装部品](toolkit.md) を使い、胴体は `loft`、鰭は `fin` または魚種専用の `Mesh` で組み立てる。輪郭、UV、アルファを実モデルで確認し、テクスチャ内蔵GLBと回転プレビューを作る。胴体の切り抜きと鰭膜の半透明を併用する場合は、GLB内で材質を分けられる出力方法を使う。

不透明な鰭は資料に合う色と模様を維持する。今回のスジアラ・カンモンハタでは胸鰭を不透明寄りにしたが、ハタ類全種の固定値にはしない。癒合した腹鰭、存在しない鰭、着底時に隠れる腹鰭を一般魚の左右対称テンプレートで置き換えない。

## 水槽で動かすとき

- 胸鰭を動かす場合は基部の線を支点にし、角度を魚種に合わせる。静止時の形と開閉時の変形の両方で、基部から先端まで向きが少しずつ変わるよう、鰭の長さに沿って曲がりを分散させる。上面から見て途中に折れや波打ちがないことを確認する。
- 背鰭・臀鰭の接合帯は胴体と同じ変形を受けるようにし、ひらき・折りたたみ・はためきは外側へ向けて強める。止まった姿勢だけで判断すると、動かしたときに付け根が離れることがある。
- 側面・正面・上面・下面・斜め後方から、静止、開閉の途中、閉じた姿勢、通常の遊泳や旋回を確認する。軽量モデルを出す場合は同じ箇所を軽量版でも見る。膜を通して胴体や背景が見えるか、尾柄の輪郭と鰭の付け根がつながるかを拡大して確認する。静止GLBで確認したことと、水槽側の描画・変形を確認したことを分けて記録する。
