# ハゼ類・ヨシノボリ類の参照図

ルリヨシノボリとビワヨシノボリの制作で繰り返し修正した点をまとめる。以下の形態メモはユーザー提供写真と制作時の指定に基づく。分類群全体の診断や、別個体にも必ず当てはまる標準形態とは扱わない。

## 写真の役割を分ける

- 正面写真は頭部の横幅と高さ、頬・眼の張り出し、口の弧を読む。上面写真は頭の幅と吻の丸み、胴体から尾柄への絞り込みを読む。側面だけから細い紡錘形の頭にしない。ルリヨシノボリでは、正面から少しつぶれた丸い輪郭へ修正した。
- 体形資料と色資料を分ける。暗く写った別個体の正面写真から形と模様の配置を採っても、承認済み個体の明るい体色まで暗くしない。
- 体表に残す同定形質、雌雄差、個体差、光や容器の反射、ユーザーの書き込みを区別する。尾鰭の一点の黒斑を「標準的特徴ではないので除く」と指定された場合、その点だけを除き、帯・鰭条や鰭縁まで消さない。

## 模様は文字名だけで指示しない

V字や横倒しの「ハ」の字は、画像の左右で向きが逆転しやすい。頭側／尾側、背側／腹側、両枝の始点と終点、交点の有無、広がる方向をランドマークで記録する。ユーザーの位置指示画像があれば、文字の慣用的な向きよりその図を優先する。

- ルリヨシノボリの尾柄斑：今回の指定は尾鰭基部付近の短い二つの斜斑。太さを少し持たせ、淡くにじんだ黒で不明瞭にする。向きは位置指示画像に合わせ、長い鋭い黒線や赤い案内線へ置換しない。
- 眼前のV字：今回のヨシノボリ類では、左右の眼前から吻の中央寄りへ向かう模様を再現した。交点は吻端・唇に届かず、その手前に置く。ルリ個体は明るい赤、ビワ個体は赤茶色という指定を別に保持する。V字の存在・位置・色を全ハゼ類に自動適用しない。
- 位置、長さ、幅、濃さ、縁のぼけを別の調整項目にする。「薄く」は短くすることや、形をぼかして消すことと同義ではない。

## ビワヨシノボリの雌雄を描き分ける

今回の雌写真に合わせて採用した差。別資料ではその資料を優先する。

| 部位 | 雄から雌へ変更した内容 |
|---|---|
| 基本体形 | 種として共通する体形を維持し、頭や口まで別種風に作り直さない |
| 鰭 | 全体に小さめ。尾鰭は自然なうちわ形を保って縮小する |
| 鰭の模様 | 雄より淡い。第二背鰭の赤い斑紋は点列より連続した曲線、尾鰭の斑紋も連続帯に寄せる |
| 体側・腹部 | 体側の斑紋を薄くし、腹部の白い領域を強調する。白い腹まで模様を延長しない |

点列から帯へ変えるときは、元の曲線の流れに沿ってつなぐ。画面の水平線や等間隔の格子に変えない。三方向で同じ性・模様・鰭の大きさになっていることを確認する。
