# 提供されたイラストの画風を保って水槽まで作る

このリポジトリの手順は**写真の提供**を基本にしている（写真は形と模様の資料、画風は既定のアニメ調）。添付イラストを画風見本にすると決まった場合は、次の方針で制作する。

- **画風**：既定のアニメ調・セル塗り（create-fish-3d-views の「既定の成果物と画風」、ネオンテトラのアニメ調見本）を使わず、提供されたイラストの画風にそろえる。三面図、3Dモデルの表面、レイアウト案、素材テクスチャ、水槽の見た目までの全工程。
- **資料の扱い**：同じ魚の形・模様の資料としても指定されたイラストでは、絵の表現（筆致・ハイライト・紙の白・デフォルメ）と個体の特徴を分けて読む。画風専用の見本からは線・塗り・質感を採り、魚の形・模様は対象種の資料から取る。

承認の取り方、実在魚種だけを扱うこと、新しいソフトを勝手に入れないことなど、[fish-to-3d-aquarium](../fish-to-3d-aquarium/SKILL.md) の決まりはそのまま守る。

## 0. どちらの扱いか決める

| 提供されたもの | 扱い |
|---|---|
| 写真だけ | 開始時に決めた画風で進める |
| その他を選び、画風見本のイラストを添付 | イラストの画風を使う。写真もあれば形・模様の根拠は写真を優先する |
| 添付イラストの画風で作るよう明示 | イラストの画風を使う |
| イラストがあり、アニメ調またはリアル調を選択 | 選んだ画風を使い、イラストは必要に応じて形・模様の資料にする |
| イラストがあり、画風の希望なし | 既定のアニメ調を使う |

決めたことを `project.json` に記録する：
`"style": {"source": "user_illustration", "name": "透明水彩（にじみ・紙の白・細い鉛筆線）", "files": [...], "quote": "<ユーザーの言葉>"}`。

## 1. 画風を言葉にする

イラストを見て、画材・線・塗り・色調・紙・ハイライトの残し方・背景の扱いを短く書く。これが全工程の**画風句**になる（例と型は [references/style-clauses.md](references/style-clauses.md)）。「Japanese anime style, cel shading」など既定の画風句は全プロンプトから外す。

## 2. 同じ魚の資料も兼ねるイラストを照らし合わせる（①調査）

- イラストから種・品種・色の型を推定し、**ユーザーに確かめる**（改良品種・色の型は絵だけで決めない）。
- 絵の表現を模様と取り違えない：紙の白で残したハイライト、にじみ、強調された輪郭、省略された鱗。例：水彩の白い抜けを「更紗（赤白）」と読んだが、ユーザーの答えは「素赤」だった。迷う点は質問として出す。
- research.md に「イラストで確認できた特徴」「文献の特徴」「絵の表現として扱うもの」を分けて書く。

## 3. 三面図（②）

- 各プロンプトに**元のイラストを添付**し、画風句と画像の役割を明記する。同一個体の資料を兼ねる場合は「同じ個体・同じ画風」と指定し、画風専用の場合は対象種の資料を別に示す。画風参照には添付イラストを使う。
- 同一個体の資料を兼ねるイラストは厳密な側面図でないことが多い（少し斜め上からの構図など）。その場合は側面も描き直してもらう。真横に近ければ、イラストを側面としてそのまま使ってよい（ユーザーに確かめる）。
- 画像生成サービスは背景に紙色のにじみを入れがち。「無地の白い紙の背景」を明記し、入っていたら直してもらう。
- 大きな付属物が頭や体を隠す魚は**その部位を除いた参照画像**を、顔の印象が大事な魚は**正面図**も作る（create-fish-3d-views の「三方向を設計する」）。イラストで描かれた顔を3Dで推測しないため。

## 4. 3Dモデル（③）

[references/3d-from-illustration.md](references/3d-from-illustration.md) を読む。要点：

- 描き直さずに、承認済みの絵をそのまま投影して貼る。筆致・紙の白・鉛筆線が立体の上に残るのが正解。
- **絵に無い立体を足さない**（唇・鱗の凹凸など）。口や眼は描かれた絵で表す。
- 正面を向いた面は、正面図があればそれを貼る。無ければ側面の絵を引き伸ばさず、側面の色を柔らかくぼかしてなじませる。
- 形や顔の印象は、**イラストと3Dを並べた比較画像**で自分で確かめてから見せる（側面・正面・斜め）。

## 5. レイアウト案と水槽（④⑤）

- レイアウト案：承認済みの3Dモデルで配置の下書きを描き、画風句入りの「完成予想図」のプロンプトも渡す（下書きの配置に合わせて描き直してもらう）。
- 素材テクスチャ：[make-aquarium-textures](../make-aquarium-textures/SKILL.md) のプロンプトに画風句を入れる。「画風の参考のみ、魚は描かない」として、イラストを添付してもらう。
- 見た目：背景は光の影響を受けない材質で、絵の色をそのまま出す。紙の質感をごく薄く画面全体に重ねる。水中の光の模様は控えめにする（絵の色を飛ばさない）。鰭は絵の紙の白い部分ほど透けるようにすると、水彩の透明感とつながる。
- 画面の文字・ボタンの配色も画風に寄せる（紙色の地、墨色の文字、にじまない落ち着いた色）。

## 6. 伝えること

各段階で、画風をどう保ったか（何をそのまま使い、何を推測で補ったか）を短く伝える。絵の表現と特徴の取り違えが起きやすい点は、確かめた結果を書く。
