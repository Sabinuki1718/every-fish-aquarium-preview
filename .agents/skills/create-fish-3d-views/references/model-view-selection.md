# モデル用図面の選び方と側面先行の検証

## 魚体からルートを選ぶ

| 条件 | 使う図面と工程 |
|---|---|
| 胴体の断面を長軸に沿って組み立てやすい、おおむね左右対称の魚 | 側面図を生成して承認を得る。承認した側面から鰭あり・鰭なし素材を用意し、Fish Kitの試作を取り入れた[側面素材の組み立て](../../build-fish-3d-from-views/references/side-view-assembly.md)を使う。厚みや鰭基部は信頼できる上面・下面・正面資料で補う。十分な資料があれば側面の承認後に3D化へ進める。 |
| ヒラメ・カレイのように上下に扁平で左右非対称、またはマゴチのように頭幅・断面が側面だけでは読みにくい魚 | 側面を先に承認し、上面・下面をそれぞれ別の生成でそろえて三面図フローへ進む。ヒラメ類では有眼側・無眼側・側方から厚みと鰭の位置を読む。必要なら正面図や反対側も追加する。 |
| 見えない部位が輪郭、厚み、斑紋、付属器官の再現を左右する魚 | 最初の区分にかかわらず、その部位が見える方向を補う。幅・位置を決められる資料が不足する場合は、承認側面を参照して必要な方向を別画像として作る。 |

側面が承認待ちの間は、そこから派生する上面・下面、鰭なし素材の生成と3D制作を待つ。追加方向は同じ承認側面を参照し、頭尾・全長・個体設定・鰭の状態・模様位置を照合する。正中鰭と対鰭、尾鰭の薄い縁、頭幅と体幅、背腹の模様の所属面を確認する。承認側面を差し替えたら、新版の承認を得て派生図を再照合する。

## ランチュウ型金魚の上見

同じ個体の側面・真上を最初の提出でそろえる。上面では頭幅・背幅・尾筒へのつながりと尾の左右の張りを、側面では背なり・体高・尾付けを確認する。体色・斑紋・鰭の開きが両図で対応することを確認し、上見や横見の系統指定は品種資料に沿って反映する。

## 模様による追加方向の判断

体型が標準的でも、背腹・頭部・尾柄をまたぐ斑紋が側面投影で伸びる、境界で模様の密度や質感が変わる場合は、その面が見える方向を補う。形態の再現と模様の再現を別に評価し、資料の追加・UV修正で足りるか、参照画像の追加が必要かを判断する。

今回のカンモンハタでは三面図フローのほうが良好だったが、尾柄や背側の継ぎ目には局所修正が残った。一種の比較結果から「模様の複雑な全種に三面図が優れる」とは決めない。追加図も承認側面の斑紋位置・密度・輪郭の鮮明さと照合し、UVベイク後に再確認する。

## プロンプトの使い分け

まず学名と主要識別点3〜5点を短く具体化する（M）。近似種との混同や、色の境界・鰭条・雌雄差など重要な点が不十分なら、その部位を重点的に詳しくする（D）。外見の雌雄差が明瞭でユーザーが性を指定していない場合は、初回生成前に確認する。種の一致、指定した性・成長段階、実個体の色域の面積・境界・濃さ、鰭の透けや姿勢を別に見る。不鮮明な形質は未確認として記録する。

2026年11月の側面検証で得られた使い分けの例。

| 対象 | 活かせる結果 |
|---|---|
| カワヨシノボリ♂ | 詳細条件（D）のみ初回全担当が合格。指定した性の鰭形、頬・眼前の小模様、鰭の色を優先する。胸鰭条の全数は未確認。 |
| シリキルリスズメダイ | M・Dとも初回全担当が合格。尾側の黄域は色名だけで済ませず、体側への張り出し方と、青を残す鰭を指定する。 |
| スダレチョウチョウウオ | M・Dとも初回全担当が合格。2暗帯と独立した尾柄黒斑を残し、後方の黄域を別に確認する。初回の推奨はM、ユーザーが選んだ修正ベースはD。 |

第1回はオオヨシノボリ、トゲチョウチョウウオ、デバスズメダイの一括生成9組で、三方向のセットとして投影不整合が残った。承認側面を参照した方向別生成では、上面・下面を個別に検品・修正できた。比較は各種・各条件1回で、和名のみ（S）とM/Dでは学名の有無と記述量が同時に異なる。成功率、学名だけの効果、魚種別の最適条件は確定していない。第2回の側面修正版と後続方向は、初回採点とは別に扱う。
