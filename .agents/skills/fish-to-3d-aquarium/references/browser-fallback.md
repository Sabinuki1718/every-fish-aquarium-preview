# ブラウザ簡易版（Python が使えないときの③）

三面図を AI が読んで数値（fish-spec）にし、ブラウザだけで魚を組み立てる。**インストール不要・通信不要**で、ファイルをダブルクリックすれば開ける。
標準ルート（build-fish-3d-from-views）より精度は落ちるので、ユーザーにその違いを伝えてから使う。

| | 標準（build-fish-3d-from-views） | ブラウザ簡易版 |
|---|---|---|
| 必要なもの | Python・NumPy・Pillow | ブラウザだけ |
| 体の形 | 断面ロフト・曲線スイープ・独自メッシュ。エイ・タツノオトシゴなども構造ごと作れる | 頭が左の側面図に沿った紡錘形（断面は超楕円）。エイ・カレイ・タツノオトシゴなどは表せない |
| 鰭 | 厚みのある閉じた形、接合部をなめらかに | 薄い板。対鰭は付け根の線で開く |
| 口・唇 | 閉じた唇を立体で作れる | 作らない（模様で表す） |
| 模様 | 側面・背面・腹面を再投影して焼き込む | 手続き的に描く、または側面図をそのまま横から投影（背と腹は伸びる） |

エイ・カレイ類・タツノオトシゴ・ウナギの強い曲がりなど、側面図の紡錘形で表せない体型では、ブラウザ簡易版では作れないことを伝え、標準ルートのための Python の導入を提案する（[環境の確認](environment-check.md)）。

## 作り方

1. `species/<id>/model/browser/` を作り、このスキルの `assets/` から2つをコピーする。
   - `fish-viewer.html` → `index.html` に名前を変える
   - `fish-viewer-runtime.js`（そのまま）
2. 承認済みの三面図を見て、`fish-spec.js` を書く（書式は [fish-spec の書式](browser-fallback-spec.md)）。
   ```js
   window.FISH_SPECS = [
     { "id": "…", "name_ja": "…", "scientific_name": "…", "length_cm": 13, "source": "three_view", "body": { … }, "fins": [ … ], … }
   ];
   ```
   - 座標は全長 = 1、吻端 x=0、尾鰭の後端 x=1、y は上が正、y=0 は吻端の高さ。**頭が左の側面図**で読む。
   - 側面図から：背側輪郭 `body.top`、腹側輪郭 `body.bottom`（どちらも鰭を除く）、尾柄の後端 `body.end_x`、各鰭の輪郭 `fins[].outline`、目 `eye`。
   - 背面図から：半幅 `body.half_width`（胸鰭を除く）。腹面図・正面の資料から断面の角ばり `section_exponent`。
   - 点は輪郭の曲がり具合に応じて 10〜40 点。画像の上で体長を 20 等分した目盛りを想定して読むと誤差が出にくい。
   - ①の特徴を `traits` に並べる（プレビューでチェック欄になる）。
   - 模様は `appearance.base_colors` と `markings`（帯・縦帯・斑点・斑紋・多角形・網目）で描く。
3. ユーザーに `index.html` をブラウザで開いてもらう（AI がブラウザを操作できるならそれで確認してよい）。
   - 側面・背面・腹面・正面・斜めのボタン、ドラッグで回転、ホイール・ピンチで拡大。
   - 承認済みの**側面図の画像を画面にドロップ**すると、その絵を体の模様に使い、「側面図を重ねる」で輪郭のずれを比べられる。範囲がずれる場合は `appearance.texture_bounds`（側面図の画像が覆う範囲 x0〜x1・y0〜y1）を直す。
   - 「画像を保存」で確認画像、「GLBを保存」で GLB をダウンロードフォルダに保存できる。
4. ユーザーと一緒に、①の特徴を1つずつ確かめる。ずれは数値を直して再読み込み（F5）で確かめる。
5. OK が出たら、ユーザーに「GLBを保存」を押してもらい、保存された GLB を `species/<id>/model/` に置く。
   - 書き出す GLB はメートル単位、+Y が上、頭が -X。build-aquarium-from-fish-model にそのまま渡せる。
   - 側面図をドロップしていた場合は、その模様ごと GLB に入る。

## 注意

- ブラウザ簡易版のモデルは、三面図の絵を「なぞった近似」。見えない部分の形を実測したように説明しない。
- `fish-spec.js` は JavaScript なので、文字列の引用符や末尾のカンマに気をつける。開いて「読み込み中」のまま止まる場合は書式の誤りを疑う。
