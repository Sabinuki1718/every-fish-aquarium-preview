# 鰭の欠け・接合部・遊離した条の修正

## 欠けて見えるときの切り分け

元図、テクスチャ付きの実メッシュ、鰭だけの表示を比較する。閉じたメッシュの検査だけでは、見た目の欠けは見つからない。

- シルエット自体が細い、先端がない：輪郭の読み取り、簡略化、外周まで巻き込む埋め込み変形を確認する。膜の広がりと先端位置を元図から復元する。
- 膜はあるが縞や白い帯で欠けて見える：島の重複、パッキング状態、UV、背景の混入を確認する。上書きされた画像を再ベイクする。
- 付け根だけ途切れる：実際の体表位置と付け根の位置を断面で比較する。見える外周は維持し、接続する根元だけを調整する。

白い膜や反射は残す。背景色の除去は意味的な輪郭の近傍に限定し、全面の白色判定で膜に穴を開けない。別の棘が同じ投影範囲に重なるときは、単純な最上端・最下端走査からその棘を除外する。

## 尾柄と尾鰭をなじませる

尾柄の端を平らなキャップで閉じ、厚い尾鰭の前面壁を重ねると段差や貼り付けた感じが出やすい。丸い尾柄から薄い鰭へ、断面の高さ・厚み・接線方向を滑らかに変える。

連続面で作る場合の要点：

1. 接続する完全な断面リングを決める。胴体の終端と鰭の始端には同じ頂点位置・分割を使い、間のキャップや前面壁は作らない。
2. 鰭の厚みはリングの丸みから膜へ徐々に減らす。側面だけでなく斜め・背面から見て、角ばった付け根や急な膨らみがないか確認する。二叉の切れ込みを面で埋めない。
3. 共通リングでは法線も連続させる。別メッシュなら結合した面から法線を計算し、共通頂点へ同じ値を戻す。UVを分けても法線は連続にできる。
4. テクスチャのリング上の色は周方向も合わせ、尾柄色から鰭色へ移行する。形状の境目と異なる投影を急に切り替えたり、目立つ模様のある体表パッチをそのまま引き伸ばしたりしない。
5. 鼻先・胴体・尾鰭を組み合わせた閉じた表面として辺の接続を検査する。接続前提の開いたパッチ単体へ閉鎖検査を強制しない。重なった閉じた物体が各々合格しても、接合の連続性は保証されない。

独自の表裏パッチを外周で厚みゼロにする場合、外周同士を結ぶ内部対角線上まで表裏が接触しないようにする。内部辺へ厚みを持つ中点等を設けて分割する。三角形の重心を増やすだけでは元の内部対角線が残り、そこで4面が重なることがある。通常の薄い閉じた鰭なら `fin` を使い、この処理を不要にする。

## 条が遊離して見えるとき

ユーザーが呼ぶ鰭名だけで対象を決めず、添付位置をメッシュと元図へ対応付ける。腹鰭、尻鰭前方の棘、長く伸びた鰭条を区別する。

資料で独立する棘・遊離条を、すべての魚で膜につなぐ既定にはしない。根元が体表から浮く不具合と、資料通りに独立している形態は別に扱う。ユーザーが指定部分をつなぐよう求めた場合は、その局所修正として接続する。

接続する際は条の根元から隣の鰭へ続く薄い膜を作り、条・膜・本体の外周と厚みを整える。矩形の膜パッチを重ねて終えず、可能なら対象の鰭を一枚の閉じた形状と専用UV島へまとめる。追加する膜には近傍の膜の質感を用い、元図の白背景や別の棘の輪郭を貼らない。接続先の鰭条の色・方向へつなぎ、補修部分だけ灰色や黄色の板になっていないか拡大して確認する。
