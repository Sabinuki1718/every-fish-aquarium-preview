# Tripo 製の魚モデルに鰭のリグを入れる

**ユーザーが明示的に依頼した部分修正は、修正とその確認・再修正を主担当だけで行う。** 検品体制は fish-to-3d-aquarium の規則に従う。

外部生成（Tripo 等、[外部3Dツール](../fish-to-3d-aquarium/references/external-3d.md)）の魚は、鰭が胴体と1つのメッシュになり、胸鰭が体に貼り付いた形で、テクスチャにも鰭が描き込まれていることが多い。そのまま頂点シェーダーで揺らすと「膜が上下に動くだけ」「付け根が固定されて糸を引く」「破片が浮く」になる。2026年11月の青色金魚水槽（`projects/goldfish-aquarium`）で、ユーザーの指摘を受けて直した順にまとめた。

## 前提と準備

- モデルは1メッシュ・1テクスチャ。頭 −X・背 +Y・全長 0.12 に正規化してから使う（`projects/goldfish-aquarium/shared-model/tools/final.py` の向き変換を参照）。
- 余分な鰭（Tripo が胸鰭の上などに作る独立した小部品）は、連結成分を数えて取り除く。どれを消すかは描画で赤く示してユーザーに確認する。
- 品種違いで形を共用する場合は、形状1つにテクスチャを品種ごとに用意する（写真の投影ベイク：`shared-model/tools/bake.py`）。
- 新しいソフトは入れない。Python・NumPy・Pillow と three.js（r170）だけで行う。

## 手順

### 1. 鰭を判定する（`scripts/fin_mask.py`）

- 頂点ごとに法線の裏側へ光線を飛ばし、反対面までの距離＝厚みを測る。薄い（全長12cmで約3.5mm未満）所が鰭。
- 胴体の楕円断面（厚い頂点から X 区間ごとに推定）の外にはみ出した所も鰭にする。頭部（X < −0.042）は除く（えら蓋の誤判定を防ぐ）。
- **種類（尾・背・胸・腹・尻）は頂点ごとではなく、鰭のつながった1枚ごとに、付け根側の位置で決める。** 頂点ごとに決めると、後ろへ伸びた腹鰭の先端が尻鰭扱いになり、骨に付かず「足」のように取り残される。
- 胸・腹と判定された小片（14頂点未満）は胴体に戻す。
- 出力: `fin`（0〜1）、`root`（胴体からの距離）、`kind`、`ed`（胴体楕円からの距離）。

### 2. 胸鰭・腹鰭にボーンを入れる（`scripts/fin_rig.py`）

- 各鰭（左右）に **付け根ボーン＋先端ボーン** の2本。
- **付け根は「胴体からの距離」ではなく、鰭の前端（体に最も沿った頂点のうち一番前）** に置く。Tripo の胸鰭は体に寝ているので、胴体からの距離は内側の縁全体で≈0になり、それでウェイトを付けると内側の縁が固定される（ユーザー指摘「奥側の起点が固定」）。
- ウェイトは付け根点からの直線距離で付ける：0.6〜3.5mm でなめらかに 0→1、先端ボーンは長さの20%以遠で増やす。鰭片の頂点は判定値に関係なく 3.5mm 以遠で骨に完全追従させる。
- 付け根ボーンには鰭の面に沿った座標系（x=付け根線、y=鰭の外向き、z=鰭面の法線）を持たせる。幅方向のスケールで鰭条の開閉、z軸回りで先端のしなりを表せる。

### 3. 体と癒着した鰭を切り離す（`scripts/paired_fins.py`）

- **鰭の膜の切れ端の取り込み**：判定から漏れた鰭のすぐ隣の小片（30三角形以下、鰭から2.5mm以内）に、隣の鰭頂点のウェイトを写す。しないと白い破片が浮く。
- **癒着の切り離し**：動く鰭頂点と動かない体頂点をつなぐ三角形のうち、付け根から5mm以上離れたものは、**体側の頂点を複製して複製側を鰭のボーンに付ける**。三角形を削除すると鰭の膜まで消えてボロボロになる（実際に起きた）。体側は元の頂点で閉じたまま残る。
- 鰭に触れる三角形はすべて両面描画の鰭として描く（片面のままだと回したときに欠ける）。

### 4. 描画（`references/runtime-snippets.js`）

- 鰭は2パス：深度だけ書く `finDepth`（renderOrder 1）→ 色を重ねる半透明 `fin`（renderOrder 2, depthWrite false）。重なった尾鰭が角度によって前後入れ替わる破綻を防ぐ。
- 半透明度は明るさから：淡い膜は透け、黒い筋と付け根は不透明。
- 尾・背・尻鰭は頂点シェーダーで（付け根からの距離×角度で揺らすので付け根は外れない）。胸・腹鰭はボーンで（同じ頂点をシェーダーでも動かさない＝二重適用しない）。

### 5. 動き（ユーザーの参考動画で確認した金魚の使い方）

- 胸鰭は **「休む」と「漕ぐ」をはっきり切り替える**。休む＝腹に沿って寝かせて静止（0°）。漕ぐ＝決めた回数（止まり・つつき・パクパク時3〜6回、泳ぎ中1〜2回）を全振幅で漕ぎ切ってから休む。1回約0.7秒：素早く下ろして鰭条を開き、ゆっくり戻る。左右交互。
- **まっすぐ巡航中は漕がない**。漕ぐのは停止/低速・減速・浮上/潜航・旋回のとき。魚の実際の速度を体座標で測って判定する。
- **漕ぐ向きを進行方向に合わせる**：前進＝斜め後ろ下、浮上＝真下、潜航＝前寄りの下、減速＝前。向きは漕ぎの合間に切り替える。振れ角は最大約57°。
- 腹鰭は下向きが基本姿勢（付け根線を軸に下へ回す。ねじらない）。動きは数度だけ。
- 旋回は体を傾けず、向きを滑らかに追従させ、体を内側へ弓なりにする。経路は角の丸いトラック形（半径は体長の半分以上）。

### 6. 体に描き込まれた胸鰭を消す（`scripts/patch_flank.py`）

- 写真投影や Tripo のテクスチャには、体に貼り付いた胸鰭が描かれている。鰭が動くと「描かれた鰭」が残る。
- ユーザーに **同じ個体の胸鰭なしの横向き画像**（左右。片側だけなら左右反転）を画像生成で作ってもらい、モデルの横の輪郭に合わせて（IoU 0.75 以上を目安）、えらの後ろ〜腹鰭の手前の体側下部だけを塗り直す。周囲に色を合わせ、境界をぼかす。
- 画像が無いときの代替（`scripts/clean_fin_shadow.py`、鰭の近くを体の少し上の肌で塗る）は、描かれた鰭がモデルの鰭より長いと取り残しが出る。
- 左右の画像を取り違えると IoU が 0.6 前後に下がる。下がったら入れ替えて再実行する。

## 確認

- 静止した魚を横・斜め前・斜め下から 0.1 秒おきに 8〜12 コマ撮り、鰭が付け根を軸に一体で動くこと、糸・破片・欠けがないことを見る。
- 胸鰭の角度を 0.1 秒ごとに数値で記録し、休み（0°が続く）と漕ぎ（毎回 0→約57°）が分かれていること、巡航中は 0° であることを確かめる。
- 鰭や体のテクスチャを直したら版を上げて記録し（`technical_revision`）、承認済みの版を上書きしない。
