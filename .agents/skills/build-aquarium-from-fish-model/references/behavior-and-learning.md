# 行動・構成・学習情報

魚種の生息環境・行動を水槽へ反映する際に読む。資料で確認した生態と、画面で観察しやすくする演出値を分ける。今回の沖縄の漁港下の水槽は実装例であり、匹数・全長・周期・経路を別水槽へ固定しない。

## 居場所と状態遷移

遊泳層だけでなく、居場所と行動の切替を設計する。例えば底付近を探索する、岩の隙間に留まる、隙間から出て周囲を泳いで戻る、混群を作る状態を分ける。魚種ごとの根拠は調査記録に残す。

### 岩の隙間に居つく魚

- 隙間は複数の石の間の実空間として作る。魚を中身の詰まった岩の内部へ隠したり、岩を透かして代用したりしない。
- 居付き→出入り口を通る→短く周囲を泳ぐ→戻る経路を定義する。単に岩のそばを上下に漂わせる表現と区別する。
- 隙間を作る石を一つの編集グループにし、空間・入口・魚の拠点をその局所座標に持たせる。移動・回転後も隙間の幅と拠点が対応するようにする。
- 衝突判定の粗い箱で隙間の空間全体を塞がない。個体の外形と入口の幅、可動中の鰭も確認する。
- 外出周期や滞在時間は観察用の設定として調整し、野生での固定周期を示す値と説明しない。

### 探索と群れ

底付近を探索する魚は、実際の地表と魚体の下面から遊泳高さを決める。原点の高さだけで接地・底付近の表現を決めない。

今回のオヤビッチャとロクセンスズメダイは混群として構成した。複数種を混ぜる場合は共通の群れの空間・経路に個体差を付け、種別の二つの閉じた経路を並べるだけにしない。すべての魚種の混泳・混群へ一般化せず、資料と展示意図に応じて選ぶ。

着底は[底生魚の動作](bottom-dwelling-motion.md)、採餌・膨張は[魚種別アニメーション](../../build-fish-3d-from-views/references/species-animation.md)を参照する。

基本姿勢、頭部の傾き、着底、ホバリング、巣穴との距離を魚種ごとに記録する。角度や周期などの実装値は対象モデルで検証する。ヤシャハゼの例では巣穴付近での斜めのホバリングを再現し、腹鰭先端の黒斑の有無による雌雄の見分け方を解説する。

### 共生ハゼとテッポウエビ

対象の組み合わせごとに巣穴付近での定位、見張り、出入り、ホバリングを資料で確認する。水槽では巣穴入口の往復を通して魚が岩にめり込まないことと、エビがその組み合わせに適した範囲で巣穴周辺を動くことを確認する。

## 最新構成と学習情報

最新の展示構成を一つのデータにまとめ、モデル読込み・配置・UI・検品で共用する。実行コードへの接続も確認し、設定ファイルを置くだけで対応したとしない。

| 内容 | 記録するもの |
|---|---|
| 個体・魚種 | 安定したID、和名・学名、性・成長段階・色彩設定、モデル版・ファイル |
| 展示構成 | 匹数、表示全長と単位、遊泳層、群れ・拠点のID、行動と演出設定 |
| 観察情報 | 標準和名、学名、短い特徴または生態解説、根拠URL。地方名を表示する場合は地域と対象範囲、未確定点 |
| 履歴 | 承認された図・モデル・配置、後から承認された変更、最新構成の版 |

表示全長は親ノード変換を含む実モデル境界と照合し、全長の定義を記録する。初期姿勢のどの境界を使ったかを明記し、膨張中等の変形で全長を毎回正規化し直さない。実測値・資料の代表値と、今回の展示上の想定値を区別する。

当初の承認レイアウトは来歴として保持し、その後の承認済み変更を最新構成と履歴へ反映する。UIや検品の匹数・全長が旧設定のまま残っていないか確認する。承認の扱いは[進行の記録](../../fish-to-3d-aquarium/references/workflow-state.md)に従う。

地方名は地域差と対象範囲を調べる。一種専用の名前か、複数種をまとめた呼称かを区別し、標準和名・学名との対応と出典を残す。モデルに採用した性・成長段階も表示情報と一致させる。

既定では生体を選択したときに、標準和名・学名・短い解説を、観察対象と重ならない開閉可能なパネルに表示する。解説は識別点や行動を1〜2文で示す。詳しい出典や地方名は必要に応じて追加する。個体を切り替えた際の学名と解説、同種の雌雄、タッチ画面での読みやすさを確認する。
