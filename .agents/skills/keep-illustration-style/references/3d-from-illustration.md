# イラストの三面図から3Dにするときの注意（水彩金魚水槽の修正履歴から）

build-fish-3d-from-views の手順の上に重ねる。実装例：水彩の金魚水槽（水泡眼の組み立て：[`build-fish-3d-from-views/examples/carassius-auratus-suihogan/build.py`](../../build-fish-3d-from-views/examples/carassius-auratus-suihogan/build.py)）。

| 起きたこと | 原因 | 対処 |
|---|---|---|
| 鼻先に放射状の継ぎ目 | 側面・上面・下面の投影が先端の1点に集まる | 先端の数mmは側面の投影だけにする |
| 正面に白い斜線（×字） | 前を向いた面で、向きの重みで3投影を混ぜた境目が交差 | 前向きの面は正面図を投影。無ければ側面の絵だけをぼかして覆う（方向で混ぜない） |
| 口が2つに見える | 下面図の口・のどの白い筋が下あごに貼られた | 下面図の口・のどを周りの色で塗り消す。口は側面（と正面）の絵だけで出す |
| 取ってつけたような口 | 絵に無い唇の立体（closed_lips）を足した | 絵に無い立体は足さない。口は絵で表す |
| 横からは似ているが上からは別物 | 側面に合わせて眼を移した | 隠れた部位を除いた参照画像で頭と眼の位置を決め、付属物は別パーツで重ねる |
| 眼が付属物に埋まる | 付属物（水泡）を胴体と同じ高さ・向きで置いた | 付属物を実物どおり傾けて垂らし、眼をその上端に、上外向きに置く。正面図があれば少し前向きに |
| 顔の印象がイラストと違う | 側面の一枚の絵だけで判断 | イラストと3Dの側面・正面・斜めを並べた比較画像で確かめてから見せる |

## 画風を保つための細部
- 絵の上の眼・口・鰭の条は、立体ではなく貼った絵で見せる（眼は、絵の眼をドームに貼るのがよかった）。
- 鰭は絵の紙の白い部分ほど透けるようにする（水槽では輝度と彩度から透明度を作った）。
- 半透明の付属物（水泡）は別の材質（alpha blend）にし、承認済みの各方向の絵を向きに応じて貼る。
- 描画の確認は、プレビューと同じ描画（three.js）でも行う。ソフトウェアの簡易描画では透け方が違う。
