
## 更新 v5：Fish Kitに近い鰭制御
- 全10魚種の胸鰭を基部から開閉し、先端に遅れを付けて滑らかにしならせます。背鰭・尻鰭には独立した倒れ・揺れ・細かな波を追加しました。
- 水槽内ではFish KitのfinWhim / finMove / flutterを参考にした連続制御を使用。速度・旋回・岩の隙間での滞在状態に応じて動きを調整し、個体の位相をずらします。魚種別の形状と既存の接合部に合わせて可動量を制限した移植で、Fish Kitそのものと完全に同一の動作ではありません。
- 配布GLBには16ポーズを補間する2.4秒の基本ループを保存。水槽の連続制御とは異なり、単体GLBだけでは速度・旋回への追従はしません。水槽では基本ループの鰭モーフをGPU転送前に除き、専用シェーダーで制御します。
- ハリセンボンは背鰭・尻鰭を強めに動かし、膨張を維持。全種で視線固定、口と鰓、形状・UV・材質、サイズと生態別配置、BGMを保持しました。
- 通常／軽量計20GLBの固定頂点・元の形状／UV／材質／鰭以外のモーフを検査。両描画モードで75匹の表示、全10種の鰭シェーダー、独立位相、膨張とBGMを確認しました。検査記録は ../okinawa-harbor-fin-motion-v5/geometry-qa.json と runtime-qa.json。
