# ダンゴウオ 3色の3Dモデル v1

緑・ピンク・白の成魚（雌を想定）を各1体。全長約3cmは表示用の仮寸法です。Y上、頭-X、左右±Z。18パーツ、各35,648三角形。GLBには2048×2048pxのPNGを内蔵し、胴体は不透明、鰭のみBLEND材質です。

index.htmlから各個体のpreview.htmlを開くと、通信不要で回転・拡大できます。GLBも同じ形状・UVデータです。一般的なglTF 2.0対応ソフトへ読み込めます。プレビューは簡易照明で、PBRや透過の見え方は利用アプリにより異なります。

参照はこれまで制作した4方向図です。側面から体高、背面から厚みを読み、球状の前半身と細い尾柄を独立した断面列で構成しました。左右の眼・胸鰭、背鰭2基、臀鰭、尾鰭、単一の吸盤、横に広い閉じた上下の唇を別パーツにしています。

胴体側に残る眼・胸鰭・吸盤の絵を近傍の同体色の模様で補い、側面・上面・下面の色場を滑らかにブレンドしてUVへ焼き込みました。source_cleaned.pngに加工後の色場、texture.pngに実際のアトラスがあります。見えない部分や除いた部位の下の模様は補間であり、原画の完全復元ではありません。

各個体に6方向の実メッシュ確認画像、口と尾柄の拡大、model_spec.jsonを収録。validation.jsonはGLB構造・埋め込みPNG・材質分離・有限値・法線・インデックス・縮退面とオフラインHTMLを検査した結果です。ブラウザーのfile URL自動操作はポリシーで拒否されたため、ブラウザー実機での回転操作確認は未実施です。

魚のGLBは静止モデルです。水槽での遊泳・鰭の動き・素材配置の実装は、別途提示したレイアウト案の明示的なOK後に行います。ホンダワラと黒い丸石の完成予想画像だけを稼働済み水槽と扱っていません。
