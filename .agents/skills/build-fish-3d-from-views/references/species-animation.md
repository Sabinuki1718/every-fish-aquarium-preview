# 魚種別の姿勢と特殊動作

今回のミズタマハゼとハリセンボンの制作から得た実装例。魚種ごとの資料とユーザーの意図を優先し、角度・周期・粒数等を別の魚の既定値にしない。生態の根拠、造形上の近似、観察用の演出設定を分けて記録する。

## ミズタマハゼの着底・遊泳・採餌

着底／遊泳／砂を含む／咀嚼／鰓からの排砂を状態として分け、姿勢と鰭の形を切り替える。着底時と遊泳時の承認図を併用し、対応する基部と体形を保つ。

- 着底では、うちわ状の胸鰭の配置と支持を確認する。側面で隠れる腹鰭も立体として保持する。眼は頭部に対して自然な方向を保ち、上から見たカメラへ向けない。
- 遊泳の胸鰭は胴体の外側でゆっくり開閉し、最大閉鎖時にも埋まらないようにする。基部が浮かないことも確認する。
- 砂を含む動作は、胴体の位置を保ち、頭部を下へ向けて口先を砂へ入れる表現にする。頭部の長さを伸ばしたり、全身を大きく前傾させて代用したりしない。
- 頭部の主要領域は形を保って回し、胴体との接続部で変形をなじませる。これは可視的な動きを作る近似であり、魚に独立した首関節があるという解剖学的な主張にしない。
- 口先を下げる→砂を含む→戻す→咀嚼→鰓から排砂の順序と、粒子の発生位置を口・鰓の可動に同期させる。支持用の鰭と胴体を必要なく引きずらない。

砂・石への接地は[底生魚の接地](../../build-aquarium-from-fish-model/references/bottom-dwelling-motion.md)を使う。粒子はGLB内の形状で表す方法と水槽側で発生させる方法を選べるが、[モデル機能一覧](model-contract.md)に実装先を記録する。

## トビハゼ類の陸上移動と遊泳

接地、胸鰭での蹴り出し、遊泳、着地への切り替えを、対象種の体形と胸鰭の支点・可動域に合わせる。陸上での胸鰭の支持、遊泳時の引き戻し、着地に向けた開き方を切り替え区間も含めて確認する。採餌や眼の引き込みは対象種の資料で確認できた姿勢・動作を採用する。

## 鰭の動き

[標準の鰭アニメーション](fin-animation.md)を魚種の推進様式へ合わせる。ハリセンボンは背鰭・尻鰭を主に動かし、存在しない腹鰭を追加しない。ミズタマハゼは着底時の支持と遊泳時の緩やかな胸鰭開閉を区別する。特殊動作中も鰭の接続を保ち、透明度は可動と別に判断する。

## ハリセンボンの膨張

通常状態と膨張状態の資料を見比べ、同じ個体・同じメッシュと模様で連続的に変形させる。別々に生成した参照画像は形態の目標であり、頂点や模様の一対一対応を保証するものではない。

- 胴体・腹部の膨張と棘の起立を分ける。全身の等倍率拡大で済ませない。
- 眼・口の局所的な形を保ち、膨張する体表への付着位置を更新する。鰭・棘の基部も体表に追従させる。
- その種に存在しない腹鰭や、一般魚の大きなエラブタを追加しない。
- 通常・最大膨張だけでなく中間状態で、隙間・交差・模様の引き伸ばし・棘の向き・眼の埋没を見る。
- 膨張と呼吸・鰭の同時再生でも確認する。モーフの単純加算で付着位置が崩れる場合は変形の順序や補正を見直す。

自動膨張を設ける場合は、防御反応を見せる観察用の演出であると示す。一定周期で自然に膨らむ習性と説明しない。手動操作との優先関係、戻る動作、自動演出の停止を定義する。
