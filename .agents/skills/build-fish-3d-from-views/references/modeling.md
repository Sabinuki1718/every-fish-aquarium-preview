# 三面図を魚ごとの構造に変換する

## 図の正規化

元画像を保存し、各パネルの矩形、頭尾方向、回転、頭端・尾端、胴体境界、鰭の付け根を記録する。図のラベル、魚の外接矩形、影を混同しない。正規化した長軸位置で側面と上下面を合わせ、倍率差を補正する。側面が右向き、上面が左向きといった場合も明示的に変換する。

既定のモデル座標はY上、頭-X、尾+X、左右±Z。長軸をXに置けない曲がった魚は、局所座標で組み立てて最後にY上へ配置する。実寸を指定する場合は全パーツを一括で換算する。

ランドマークは必要な密度で増やす。目安となる位置は口、眼、鰓蓋、体高最大部、各鰭の付け根、尾柄、尾鰭端。断面半径は正に保ち、端では単一の極点か閉じたキャップへつなぐ。重複した極点を1周作ると縮退三角形が出る。

## 体型で組立方法を選ぶ

| 図から読める特徴 | 選ぶ構造・注意 |
|---|---|
| 紡錘形、側扁した硬骨魚 | 断面ロフト。体高と厚みを独立に設定し、胴体と鰭の輪郭を分離する |
| ウナギ、長いタチウオ類 | 細かな断面と中心線スイープ。連続した背鰭・尻鰭を太い胴体として扱わない |
| サメ、非対称な尾鰭 | 尾柄と上下葉を別形状にする。左右対称は上下対称を意味しない |
| エイ、扁平な底生魚 | 胴盤・胸鰭の広い面を上面から構成。薄いY断面、広いZ断面。鰓裂と口が腹面にある場合はそこへ配置する |
| カレイ、ヒラメ類 | 眼側と無眼側を別の色場で扱う。左右へ眼を機械的に複製しない |
| タツノオトシゴなど | 曲線スイープや複数の局所メッシュ。口吻、曲がった尾、稜を別に構成。X軸ロフトへ押し込まない |
| フグ、箱形・装甲形 | 非楕円の断面、専用面パッチ、棘・稜。ロフト半径だけで表せない特徴は独自メッシュへ |

これは選び方の例で、魚種の固定テンプレートではない。見えている資料が優先。見えない部分は自然な補間にとどめる。

## 鰭・眼・付属器官

- 三面図の各パネルにある鰭を、同じ鰭の別投影か別のパーツか判定する。対鰭は左右それぞれの付け根・開き角・厚みを持つ独立形状にする。資料で欠く魚に腹鰭を追加しない。
- 鰭は表裏と縁を閉じた薄い立体にする。厚みは全長との比率で決め、針金ほどの薄さや胴体ほどの太さを避ける。根元は胴体に少し埋め、隙間・面の競合を避ける。
- 鰭条は画像の陰影で足りる場合はテクスチャに残す。大きな棘や分枝だけ形状にする。透明にするなら鰭専用の意味的なマスクを用い、胴体の穴と混同しない。
- 尾柄の棘、髭、口吻、腹部の突起、脂鰭などを一覧化し、色補修の対象と別形状に分ける。
- 立体眼を作る場合、胴体側の眼の絵も消す。左右の数・位置は図で決める。
- 輪郭の簡略化で鰭膜を細い帯に削らない。外周・内周・付け根を拡大図と照合する。根元を埋める量はその断面の体表から決め、外周まで一律に移動して鰭を縮めない。

## 閉じた口

口の拡大図を、側面・上面・下面から読む。閉じた図では上下の唇の合わせ目が細い線になる。前から横幅が広く、上から弧状に見えるなら、左右へ広がる唇を作り、口角を後方の頬へ連続させる。上下の唇の境界は同じ位置に置く。黒い楕円を付け足すと開いた口に見える。

`closed_lips` はこの構造を作る補助で、寸法・位置・左右方向・上方向・前方向をすべて引数で渡す。細長い口吻、小さな下向きの口、サメの腹側の口等は、それぞれ局所座標と独自輪郭へ調整する。図にない厚い唇を一律に追加しない。

尖った吻と斜めに後退する口角を持つ図では、頭部の輪郭と細い顎の溝で閉口を表現できる。別の魚で使った横長の唇を移植したり、頭部を大きなぼかしで覆ってから唇を付け足したりしない。

上下の唇の後半を頬へ埋め、上面で白い隙間が見えないことを確認する。修正で口幅を変えても、閉じた状態を開口へ変えない。

## UVと描き直し

1. 独立パーツの輪郭と影をマスクにし、胴体画像から取り除く。背景色を単に貼るのではなく、周囲の体色・模様を補間する。模様の境界を跨ぐ大きな補間は境界を再構成し、ぼけた斑点にしない。
2. 胴体を長軸u・断面角v等の連続島にする。側面・背面・腹面の投影を表面上でブレンドし、口・腹・尾柄の継ぎ目を色場として解く。単純投影が伸びる部位は専用島へ分ける。
3. 鰭・突起・眼の画像は専用の島へ再配置し、UVを実形状に合わせる。鰭の余白が白く見えるときは、透明化だけに頼らず輪郭とUVを直し、島の外へ色を延長する。
4. アトラス島にはパディングを入れる。元画像の絵、影、白背景を含む外接矩形を無加工で貼らない。遠景のミップマップでも白・黄の縁が出ないか確認する。
5. 色を描き替える領域では、元の模様の境界のアンチエイリアスも除去する。明るい黄色だけを閾値で消すと、暗い黄色の細い枠が残る。意味的な領域マスクと必要最小限の拡張を使い、再描画する模様を最後にベイクする。
6. コピー元の体表にある側線、金色の帯、鰭の輪郭やぜいごが、補修先で別の線として伸びていないか確認する。尾柄の補修用には不要な線を除いた専用の色場を作り、承認済みの胴体模様や立体の突起は残す。

島の配置では、使用する棚・帯を選んでからその棚のカーソルと行高だけを更新する。幅広の島を別の帯へ置く処理で、細い島の棚の行高をリセットしない。名前とパディング込みの矩形を登録し、`check_atlas_islands` で重複・範囲外を検査してから書き込む。胴体、眼、色見本、元画像を保存する領域も検査対象に含める。同じUVを意図的に共有するパーツは同一の島として登録する。

アルファは意図的に透かす部分だけに使う。輪郭の読み取り違いで胴体・口・尾柄に穴が開かないようにする。
