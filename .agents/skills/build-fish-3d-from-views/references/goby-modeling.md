# ハゼ類の体形・顔・雌雄差をモデルへ移す

ユーザー提供のルリヨシノボリ・ビワヨシノボリ資料で判明した制作上の注意。写真で確認した特徴を扱い、全ハゼ類の解剖テンプレートにはしない。

腹鰭の結合、胸鰭の鰭条、色型、透過、採餌動作などの追加事例は [ハゼ類の制作事例と検品の要点](goby-production-notes.md) を参照する。

## 頭部と口を複数方向で合わせる

側面の高さと、真上からの幅を別々に設定する。正面資料があるときは、左右に広く少しつぶれた丸い頭、頬の張り、眼の上方への突出をその輪郭で検証する。側面だけを押し出した円筒や、正面で細い縦長の頭を避ける。資料写真の撮影角・遠近・容器越しの歪みを考慮し、写真のピクセル比を無条件に実寸比にしない。

閉口線は側面写真の上唇・下唇・口角をたどる。今回の資料では、吻から口角へ斜めに後退する線であり、顔の真横へ水平な線を引く形ではなかった。正面の幅広い弧も合わせ、唇の厚みと頬へのつながりを作る。

眼を独立形状にした後の体表には、元の眼・輪郭・影を必要範囲だけ除去する。眼上を大きくぼかすと目立つ斑になりやすい。唇も周囲の色場から採色し、元画像と異なる色の円盤・パッチを貼らない。

## V字を表面の模様として作る

1. 左右の眼前、交点、吻端、唇の位置をモデル表面のランドマークで指定する。今回の指定では交点は吻端より後方で、唇に触れない。
2. 色は承認済み個体から採る。形状確認用の暗い正面写真の赤をそのまま移植しない。ルリ個体の明るい赤、ビワ個体の赤茶色を区別する。
3. 左右の枝を頭部の連続した色場または表面座標上の曲線として定義し、UVへベイクする。Vの交点がUVの継ぎ目をまたぐ場合も、3D表面では位置・幅・色が連続するようにする。
4. 鱗や肌の細かい濃淡を保ち、必要な範囲で縁をなじませる。太い直線の後付けメッシュ、既存の模様が透けて二重になる塗り足し、顔全体のぼかしで済ませない。
5. 正面・真上・左右斜めから、Vの交点、唇との間隔、左右の曲線を確認する。平面アトラスだけでは合格にしない。

## 左右の体側・口周りの色場

右側後半だけ不自然になる場合は、左右のu反転、パネル境界、側面と上下面の混合重み、コピー元領域の不足を調べる。正常な左側を維持しながら右側を補修する。模様や鱗が長軸方向に伸びた四角い帯、上下に走る硬い継ぎ目を残さない。

唇周囲の色違いも、パーツの材質係数とアトラスの色の両方を比較する。幾何形状とUVが承認済みなら変更せず、色場の補修と再ベイクに限定する。画像・GLB・オフラインプレビューは同じ版へ更新する。

## 雌雄差と尾鰭の輪郭

基本体形を共有し、資料で異なる鰭サイズ・模様・腹色をパラメータとして分ける。雌を雄全体の均一縮小や単なる彩度低下で済ませない。今回のビワ雌では、小さい鰭、淡い体側斑、白い腹、第二背鰭の連続した曲線と尾鰭の帯を採用した。別個体に固定しない。

尾鰭は付け根を保持し、外周曲線と鰭条方向に沿って縮小する。アルファ画像の切り取りや外周頂点の削除で小さくすると、うちわ形が欠けたり歪んだりする。形状、UV、アルファの輪郭を一緒に合わせ、上下の肩と丸い後縁を横から確認する。生来の非対称・切れ込みは資料に従う。

ヨシノボリ類の腹鰭が癒合した吸盤として資料に見える場合は、その構造として作る。「腹鰭は左右二枚」という一般的な検査だけを理由に、承認済みの吸盤を二枚へ分割しない。
