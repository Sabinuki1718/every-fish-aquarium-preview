# 3Dモデル組み立ての実装例（コードのみ）

作例で承認されたモデルを組み立てたスクリプト。③で `model/work/build.py` を書くときの手本として読む。三面図などの画像は含まないので、このままでは動かない。

| フォルダ | 魚 | 見どころ |
|---|---|---|
| `rhinogobius-mizunoi/` | ルリヨシノボリ（リアル調、承認 v6） | 側面図を基準にし、正面図は頭の断面の補正にだけ使う。上面・下面の幅の食い違いの扱い。胸鰭を独立した扇に。吸盤状の腹鰭 |
| `carassius-auratus-suihogan/` | 水泡眼（水彩イラスト調、承認 v6） | 背鰭のない体形。水泡を外した参照図から頭を作り、水泡は半透明の楕円体として別に焼き込む |

- `build.py`：[`scripts/fish_mesh.py`](../scripts/fish_mesh.py) を使って GLB とプレビューを書き出す。作例では `species/<学名>/model/work/` に置き、`python build.py v6` のように版を指定して実行した
- `landmarks.json`：三面図から読み取った輪郭・目印・画像の位置。画像のファイル名は作例のもの
