# 標準の鰭アニメーション

アクアリウム用の新規モデル・水槽は、沖縄水槽で承認された **Fish Kitに近い鰭制御** を既定とする。側面図からの組立と三面図フロー、アニメ調と希望時のリアル調に共通して適用する。ユーザーの明示指定と魚種本来の構造・遊泳様式を優先する。

## 動きの基準

| 部位・状態 | 既定の表現 |
|---|---|
| 胸鰭 | 正しい付着位置を保って基部から外側へ開閉する。先端ほど位相を遅らせ、弱く滑らかにしならせる。途中に折れ目を作らず、閉じたときも胴体へ埋めない |
| 腹鰭 | 付着位置と左右・癒合の構造を保ち、控えめに開閉する。胸鰭の動きをそのまま複製しない |
| 背鰭・尻鰭 | 基部を胴体へ接続したまま、倒れ込み・左右の揺れ・小さな波を組み合わせる。部位ごとに位相と周期を変える |
| 尾鰭 | 胴体・尾柄のうねりへ接続し、先端に細かな変形を加える。尾柄と異なる大振幅の動きを重ねて接合を割らない |
| 速度・旋回 | 周期や開き具合を滑らかに変える。速度の切替で位相を飛ばさない |
| 群れ・静止に近い状態 | 個体別に位相・微小な揺らぎを持つ。居付きや観察中の移動停止でも、その種に必要な小さな鰭運動を残す |

Fish Kitの `finWhim`、`finMove`、`flutter` を参考に、ゆっくりした開き具合の変動と先端の揺れを組み合わせる。完全同期した単一正弦波や、魚全体を振るだけの剛体運動を完成形にしない。元の釣り用状態は省き、眼の動きの適用条件は[視線の仕様](model-contract.md#視線の仕様)に従う。

これは表現と接続の基準であり、Fish Kitの全挙動の完全移植や、野生個体の運動計測モデルを意味しない。10魚種で承認された実装の角度・振幅・周期を、未検証の別魚種へ一律に固定しない。

## 形状への割り当て

1. 頭尾軸・上方向・単位・親変換を調べ、各鰭の基部、自由縁、左右を定義する。特定の作例の「頭が-X」や世界座標の回転軸を流用しない。
2. 接合帯では鰭固有の変形重みをゼロにし、自由縁へ向けて滑らかに増やす。胴体のうねり・膨張に対しては基部も体表へ追従させる。「固定」は世界空間への固定ではない。
3. 胸鰭は基部からの回転と先端へ遅れる変形を連続的に配分する。回転の開始を基部から離さず、過大な波打ちを避ける。埋没を直す際、鰭全体を離して根元を浮かせない。
4. 部位別の振幅・折り畳み・先端の揺れ・可動限界を魚種と形状に合わせる。静止形状・UV・材質・元の模様を必要なく変更しない。光沢面や厚い鰭では法線の更新・変形後の陰影も確認する。
5. 既存の骨・モーフ・クリップが基準を満たす場合は再利用する。満たさない鰭だけを補い、承認済みの口・鰓・眼の挙動・特殊動作は保持する。

## 魚種別の調整

- ハリセンボンでは背鰭・尻鰭を主に使い、胴体の過大なうねりを抑える。存在しない腹鰭は作らず、膨張中にも基部と鰭の動きを保つ。[膨張](species-animation.md#ハリセンボンの膨張)と併せて確認する。
- ハゼ類の胸鰭は着底時の支持と遊泳時の緩やかな開閉を区別し、腹鰭が隠れても形状を消さない。
- 異体類、エイ、ウナギ類などは、その種の鰭構造と推進様式に合わせる。一般魚の対鰭回転を鰭盤や長い鰭へ一律適用しない。
- ハタ類の厚い胸鰭など、透明度の判断は動きとは独立させる。鰭を動かすために一律半透明化しない。[モデル機能一覧](model-contract.md)に構造・透明度・動きの根拠を記録する。

## GLBと水槽側の役割

- 納品GLBには基本の鰭ループを保存し、独立したローダーで再生確認する。水槽のシェーダーだけ動き、GLBは静止したまま、という状態を標準の可動版としない。
- 水槽では速度・旋回・居付きに応じた連続制御を使う。位相は経過時間を積算し、速度から毎フレーム直接作り直さない。個体ごとの状態を持ち、共有材質の一律更新で全個体を同期させない。
- 同じ鰭変形はGLBのクリップと水槽側で二重適用しない。手続き制御へ置き換える鰭チャンネルだけを停止・除外し、胴体・口・鰓・膨張など他のチャンネルを残す。モーフ番号を推測せず名前と仕様で対応付ける。
- 沖縄水槽の実装例では、GLBに16ポーズ／2.4秒の基本ループを保存し、水槽でそれを連続制御へ置換した。このポーズ数・周期は必須ではなく、GLB単体と水槽で速度追従等に差があれば明示する。
- インスタンシングでは個体別の時計・位相・速度・旋回・状態を渡す。通常／軽量で基本の鰭動作を維持し、不要なモーフや未参照頂点を削る場合も、他の機能の対応を崩さない。

[モデル機能一覧](model-contract.md)に、制御方式と版、部位別の基部・自由縁・可動限界、基本クリップ名、実装先、速度・旋回への対応、個体別状態、置換するチャンネル、魚種別の例外、検証した状態を保存する。GLB単体の基本ループと水槽内の連続制御を区別する。

## 合格条件

[品質検査](quality.md)と併せて、通常／軽量の実際に使う成果物で確認する。

- 側面・正面・上面・下面・斜め後方を拡大し、閉じた状態・中間・最大と時間経過で、根元の隙間、胴体への埋没、折れ、過剰な波打ち、鰭膜の欠落がない。
- 接合帯の鰭固有の変形がゼロで、胴体の変形へ追従する。変形後の座標・法線は有限で、面の潰れ・反転や不自然な陰影がない。数値上の成功だけで外観合格にしない。
- 基本ループ端、低速→高速→旋回→停止／居付きの遷移が滑らか。複数個体は異なる位相で動き、1匹の操作が他個体の状態を変えない。
- 口・鰓・膨張・採餌など実際の同時再生で、接続、模様、眼と頭部の位置関係が保たれる。
- 書き出したGLBを読み戻して基本ループを確認し、水槽では鰭制御が一度だけ適用されること、通常／軽量のシェーダーエラーがないことを確認する。

## 参照元と検証範囲

Fish KitはCC0。元キットのコードを利用する場合は同梱のライセンスを確認し、参照元・取得版またはハッシュを記録する。魚種別に調整した移植を元実装と完全同一とは説明しない。

2026年11月の「沖縄の海 ― 防波堤の下」で、タカサゴ、オヤビッチャ、ロクセンスズメダイ、オジサン、ハリセンボン、シロダイ、スジアラ、カンモンハタ、ナンヨウブダイ、ハマフエフキの10種・75匹に適用し、ユーザー承認を得た。通常／軽量の20GLBで接合帯・元の形状／UV／材質と鰭以外のモーフの保持、水槽で個体別制御・膨張・描画を確認した。未検証の魚種・端末・動作まで保証するものではない。
